使用說明

  1. 到 GitHub 建立一個 公開（Public）倉庫，例如 game-assets，並確認已有至少一個 commit（可勾選 Add a README）。
  2. 建立 Token：Settings → Developer settings → Personal access tokens → Fine-grained tokens → Repository access 選「Only select repositories」選剛才的倉庫 → Permissions → Contents：Read and write。
  3. 把 Token 貼到 ① 並按「登入驗證」，再於 ② 填入 owner、repo，按「檢查倉庫權限」。
  4. 選擇分類（傭兵／角色／動態精靈／寵物），把整批圖片拖進 ③，按「開始批次上傳」。
  5. 在 ④ 選擇「純網址」或「JSON」複製，貼進遊戲的圖片路徑即可。

注意：私人（Private）倉庫的圖片無法被遊戲直接載入，請使用公開倉庫。每張圖會產生一個 commit。GitHub 對內容建立有次數上限（約每分鐘 80 次、每小時 500 次），大量上傳請分批進行。
