① 登入 GitHub

程式只會直接呼叫 api.github.com，不經過第三方伺服器。公用電腦請用完即登出。

② 倉庫與連結設定

③ 瀏覽倉庫圖片（縮圖預覽、移動、刪除）

⚠️ 移動或刪除會改變圖片網址，遊戲中寫死的舊路徑會失效。操作後請下載路徑對照表，供遊戲端更新。刪除為永久刪除（需二次確認），GitHub 歷史中仍保有舊版但最新版本會移除。對照紀錄只存在本機瀏覽器，請定期下載備份。移動與刪除以單一 commit 完成，失敗時不會留下半完成的狀態。

縮圖直接讀取 GitHub 原始檔（新上傳的圖片不會因 CDN 快取而延遲顯示）。私人倉庫的圖片無法在此顯示。點縮圖可放大，支援左右鍵切換與 Esc 關閉。

④ 批次選取與上傳

把圖片拖曳到這裡、點擊或按 Enter 選取，或直接 Ctrl+V 貼上截圖
支援 PNG／JPG／GIF／WEBP／SVG／BMP／ICO／AVIF，可一次選多張，單檔上限 25MB

⚠️ 公開倉庫的圖片任何人都看得到，請勿上傳個人照片或未授權素材。每批以 Git Data API 建立單一 commit（超過「每個 commit 最多張數」會自動分批）。待上傳的原檔會暫存於瀏覽器 IndexedDB，清除網站資料即會消失。

⑤ 上傳結果（可直接貼進遊戲）

⑥ 歷史紀錄（最近 100 筆）

使用說明

  1. 到 GitHub 建立一個 公開（Public）倉庫，例如 game-assets，並確認已有至少一個 commit（可勾選 Add a README）。
  2. 建立 Token：Settings → Developer settings → Personal access tokens → Fine-grained tokens → Repository access 選「Only select repositories」並選取該倉庫 → Permissions → Contents：Read and write。
  3. 在 ① 貼上 Token 並登入（想保留登入狀態再勾「記住 Token」），在 ② 填入 owner、repo，按「檢查倉庫權限」。
  4. 在 ③ 瀏覽資料夾、勾選圖片後可「移動」或「永久刪除」。移動時若目的地有同名檔案，會自動加上 _2、_3 後綴。
  5. 操作後到 ③ 下載「路徑對照表」，遊戲端依表更新圖片路徑。
  6. 在 ④ 拖入整批圖片，按「開始批次上傳」。內容與倉庫相同的圖片會自動沿用既有連結，不會重複上傳。
  7. 在 ⑤ 選擇「純網址」或「JSON」複製，貼進遊戲的圖片路徑即可。

注意：私人（Private）倉庫的圖片無法被遊戲直接載入，請使用公開倉庫。GitHub 對內容建立有次數上限（約每分鐘 80 次、每小時 500 次），大量上傳請分批進行。
